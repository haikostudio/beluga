# Sécurité

## Signaler une faille

Ne l'ouvrez **pas** en ticket public. Deux chemins, au choix :

- l'onglet **Security → Report a vulnerability** de ce dépôt (signalement privé GitHub) ;
- un courriel à salut@haiko.studio, avec « Sécurité » dans l'objet.

Dites ce que la faille permet, comment la reproduire et la version touchée. Vous recevez une
réponse sous 72 heures ; la correction est publiée dès qu'elle est prête, et vous êtes crédité si
vous le souhaitez.

## Ce qui compte comme faille

Tout ce qui permet de lire ou modifier ce qu'on ne devrait pas : les projets, le coffre-fort, la
mémoire, les fichiers d'un autre compte ; de contourner la connexion ; ou de faire exécuter une
commande au serveur sans en avoir le droit.

## Versions suivies

Seule la dernière version publiée sur `main` reçoit des correctifs. Une installation se met à jour
depuis ses réglages, page « Mise à jour ».
