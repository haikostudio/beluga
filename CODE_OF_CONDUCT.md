# Code de conduite

Beluga Build est un projet ouvert à toutes et à tous. Dans les tickets, les discussions et les
propositions, nous attendons de chacun :

- de rester **courtois et bienveillant**, y compris dans le désaccord ;
- de **critiquer des idées, jamais des personnes** ;
- d'accueillir les débutants et les questions simples ;
- de respecter la vie privée des autres : on ne publie ni l'adresse, ni les données, ni les
  échanges privés de quelqu'un.

Ne sont pas acceptés : le harcèlement, les insultes, les propos discriminatoires, les contenus
sexuels non sollicités, les menaces, et le fait d'encourager l'un d'eux.

## Ce qui se passe en cas de problème

Signalez-le à salut@haiko.studio. Chaque signalement est lu et reste confidentiel. Selon la
gravité, l'équipe peut masquer un message, avertir, ou exclure quelqu'un du projet, temporairement
ou définitivement.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
