# La marque Beluga

« Beluga », « Beluga Build », le logo et le béluga blanc sont des marques de Haiko Studio. La
licence du code de ce dépôt (voir [LICENSING.md](LICENSING.md)) ne donne aucun droit sur elles.

## Ce que vous pouvez faire sans demander

- Dire que votre compétence, votre outil ou votre intégration fonctionne avec Beluga Build
  (« une compétence pour Beluga Build », « compatible Beluga »), tant que personne ne peut la
  prendre pour une création officielle.
- Citer Beluga Build par son nom dans des articles, des vidéos, des conférences et des comparatifs.
- Garder le nom dans une copie NON modifiée du code source, et dans votre propre installation,
  pour votre usage.

## Ce qui demande notre accord écrit

- Distribuer une version modifiée, ou une version construite par vous, sous le nom ou le logo
  Beluga. Une copie (fork) est la bienvenue sous son propre nom : changez le nom, le logo et le
  béluga avant de la distribuer.
- Utiliser le nom ou le logo dans le nom d'un produit, d'une société, d'un domaine ou d'un compte
  sur les réseaux sociaux.
- Proposer Beluga Build comme service hébergé sous son nom.

Questions et demandes de partenariat (par exemple pour distribuer Beluga Build sous votre marque) :
salut@haiko.studio.
